# Learning Curve — LCML Compiler

A compiler/interpreter for LCML, a small markup language, built during an undergraduate research (IC) internship.

## Context
Part of "Learning Curve," a research project on programming-language tooling for education. I forked this from a fellow student's initial implementation and, together, we extended it into a full pipeline: lexer, parser, semantic analyser, and an HTML translator. Development later moved to a private research repository, so this public version only reflects that early, exploratory phase — the codebase still shows an unfinished refactor (two overlapping package layouts) from right before the move.

## Tech Stack
- Java

## Components
- `Lexer`
- `Parser`
- `SemanticAnalyser`
- `HTMLTranslator`

## Status
Early-stage / superseded. Active development continued in a private repository; this repo is not maintained.
